# Administration Guide

This document provides a comprehensive guide for administrators of Carbon-Forum. Access the dashboard at `/dashboard` (requires Admin role).

## Dashboard Overview

The Dashboard is the central control panel for the forum. It provides a snapshot of system health, including:
*   Server Information (OS, PHP Version, Database Version).
*   Forum Statistics (Total Users, Topics, Posts).
*   Recent System Logs.

## System Configuration

Located under **Settings** > **System Settings**.

### Basic Information
*   **Site Name**: The global title of your forum.
*   **Site Description**: Meta description used for SEO.
*   **Site Domain**: The primary URL of your installation.

### Content Control
*   **Topics Per Page**: Controls pagination on the home/list views (Default: 20).
*   **Posts Per Page**: Controls pagination within a topic (Default: 25).
*   **Max Post Length**: Character limit for posts (Default: 60000).
*   **Posting Interval**: Seconds a user must wait between posts (Anti-Spam).

### Advanced Settings
*   **Allow New Topic**: Toggle to make the forum read-only for new threads.
*   **Close Registration**: Toggle to stop new user signups.
*   **Allow Editing**: Allow users to edit their own content.

## User Management

### Managing Roles
Carbon-Forum uses a Role-Based Access Control (RBAC) system:
*   **Administrator (ID: 5)**: Full access.
*   **Super Moderator (ID: 4)**: Global moderation (delete/lock any post).
*   **Moderator (ID: 3)**: Forum-specific moderation.
*   **VIP (ID: 2)**: Honorary status.
*   **Member (ID: 1)**: Standard registered user.
*   **Guest (ID: 0)**: Unauthenticated visitor.

### User Actions
*   **Search Users**: Find users by name or email.
*   **Edit Profile**: Update email, password, or bio.
*   **Ban User**: Set the user's role to a restricted state or delete the account.

## Content Moderation

### Topic Management
*   **Lock**: Prevent further replies to a topic.
*   **Sink**: Move a topic to the bottom of the list (hide without deleting).
*   **Stick/Top**: Pin important topics to the top of the list.
*   **Delete**: Soft delete (move to Recycle Bin) or Permanently Delete.

### Tag Management
Tags are the primary way content is organized.
*   **Merge Tags**: Combine duplicate tags (e.g., "js" -> "javascript").
*   **Lock Tags**: Prevent users from using specific tags.
*   **Edit Tag Icon**: Upload custom icons for tags.

## Maintenance & Logs

*   **System Logs**: View errors and warning logs generated by the application.
*   **Recycle Bin**: Recover deleted topics or posts.
*   **Cache Management**: Flush Memcached/Redis buffers if content appears stale.
